# JOD

จดทุกเทรด รู้ทุกบาท — บันทึกการลงทุนและการเทรด หุ้นไทย หุ้นต่างประเทศ คริปโต และกองทุน พร้อมเรทค่าเงินของทุกรายการ ข้อมูลอยู่ในเครื่องของผู้ใช้

## ใช้งาน

ต้องมี Node.js 22 ขึ้นไป

```bash
npm install
npm run dev          # เปิดที่ http://localhost:5173
npm test             # เทสทั้งหมด
npm run build        # สร้างไฟล์เว็บใน dist/ (ติดตั้งเป็น PWA ได้)
```

## บัญชีและเซิร์ฟเวอร์ซิงก์

แอปให้เข้าสู่ระบบก่อนใช้งาน จึงต้องเปิดเซิร์ฟเวอร์ซิงก์ไว้ด้วยเสมอ ไม่อย่างนั้นสมัครและเข้าสู่ระบบไม่ได้ เซิร์ฟเวอร์เก็บเฉพาะข้อมูลที่เข้ารหัสแล้วจากเครื่องผู้ใช้

```bash
npm run sync-server  # http://localhost:8787 · ตั้ง PORT, DATA_DIR, ALLOW_ORIGIN ได้
```

ที่อยู่เซิร์ฟเวอร์กำหนดตอน build ด้วย `VITE_SYNC_SERVER` (ไม่ตั้งจะใช้ `http://localhost:8787`) ตอนนี้บัญชีเก็บเป็นไฟล์ใน `sync-data/`

ลืมรหัสผ่าน: แอปส่งรหัสไปที่อีเมล ตอนนี้ยังไม่ได้ต่อบริการส่งเมล อีเมลจึงแสดงใน log ของ `npm run sync-server` แทน (ลิงก์ในเมลชี้ไปที่ `APP_URL` ค่าเริ่มต้น `http://localhost:5173`)

### บัญชีทดสอบ

ใช้ได้กับเซิร์ฟเวอร์ในเครื่องนี้เท่านั้น

| อีเมล | รหัสผ่าน | รหัสกู้คืน |
|---|---|---|
| `test@jod.test` | `jod-test-fc6df72b` | `VX4H-BPTD-FSSC-ZW36-ZVBJ` |

PIN ตั้งเองตอนเข้าครั้งแรก ถ้าล้าง `sync-data/` หรือรันบนเครื่องอื่น บัญชีจะไม่อยู่ ให้กดสมัครในแอปด้วยอีเมลและรหัสผ่านเดิม ในตัวจำลอง iPhone ถ้าคีย์บอร์ดเป็นภาษาไทย ช่องรหัสผ่านจะพิมพ์เป็นอักษรไทย ให้สลับเป็นอังกฤษก่อน (กดรูปลูกโลกบนคีย์บอร์ด)

## แอปมือถือ

แอป iOS และ Android ห่อ build เดียวกับเว็บด้วย Capacitor

```bash
npm run mobile:ios      # build + sync แล้วเปิด Xcode
npm run mobile:android  # build + sync แล้วเปิด Android Studio
```

ไอคอนสร้างจาก `assets/icon.svg` ด้วย `npx @capacitor/assets generate --ios --android`
