# JOD

จดทุกเทรด รู้ทุกบาท — บันทึกการลงทุนและการเทรด หุ้นไทย หุ้นต่างประเทศ คริปโต และกองทุน พร้อมเรทค่าเงินของทุกรายการ ข้อมูลอยู่ในเครื่องของผู้ใช้

## ใช้งาน

ต้องมี Node.js 22 ขึ้นไป

```bash
npm install
npm run dev          # เปิดที่ http://localhost:5173
npm test             # เทสทั้งหมด
npm run build        # สร้างไฟล์เว็บใน dist/ (ติดตั้งเป็น PWA ได้)
```

## บัญชีและเซิร์ฟเวอร์ซิงก์

แอปให้เข้าสู่ระบบก่อนใช้งาน จึงต้องเปิดเซิร์ฟเวอร์ซิงก์ไว้ด้วยเสมอ ไม่อย่างนั้นสมัครและเข้าสู่ระบบไม่ได้

เซิร์ฟเวอร์เก็บข้อมูลใน PostgreSQL (ตอนนี้ใช้ Supabase) ผ่าน Prisma ใส่ที่อยู่ฐานข้อมูลไว้ในไฟล์ `.env` ซึ่งไม่ถูก commit:

```
DATABASE_URL=postgresql://...
```

```bash
npm run db:migrate   # สร้างหรืออัปเดตตารางตาม prisma/migrations
npm run sync-server  # http://localhost:8787 · ตั้ง PORT, ALLOW_ORIGIN, APP_URL ได้
```

ตารางในฐานข้อมูล:

| ตาราง | เก็บอะไร |
|---|---|
| `users` | อีเมล รหัสสำหรับเข้าสู่ระบบที่ hash แล้ว และกุญแจข้อมูลที่ถูกล็อกด้วยรหัสผ่านและรหัสกู้คืน |
| `sessions` | การเข้าสู่ระบบของแต่ละเครื่อง (เก็บแค่ hash ของ token) |
| `password_resets` | รหัสตั้งรหัสผ่านใหม่ที่ส่งทางอีเมล (hash) อายุ 30 นาที |
| `sync_records` | ข้อมูลทุกอย่างของผู้ใช้ 1 แถวต่อ 1 รายการ แยกตามชนิด (`account`, `transaction`, `plan`, `picture` ฯลฯ) เนื้อหาเข้ารหัสในเครื่องก่อนส่ง |

ซิงก์ทีละรายการ: เครื่องส่งเฉพาะรายการที่เปลี่ยน และดึงเฉพาะรายการที่เปลี่ยนหลังเลขล่าสุดที่เคยเห็น ถ้าสองเครื่องแก้รายการเดียวกัน ใช้ของที่ส่งทีหลัง

ที่อยู่เซิร์ฟเวอร์ซิงก์ที่แอปใช้กำหนดตอน build ด้วย `VITE_SYNC_SERVER` (ไม่ตั้งจะใช้ `http://localhost:8787`)

ลืมรหัสผ่าน: แอปส่งรหัสไปที่อีเมลผ่าน Resend เมื่อตั้ง `RESEND_API_KEY` กับ `MAIL_FROM` ถ้าไม่ตั้ง อีเมลจะแสดงใน log ของ `npm run sync-server` แทน (ลิงก์ในเมลชี้ไปที่ `APP_URL` ค่าเริ่มต้น `http://localhost:5173`) · ขึ้นใช้งานจริงดู [docs/DEPLOY.md](docs/DEPLOY.md)

### บัญชีทดสอบ

สมัครบัญชีทดสอบเองในแอป แล้วเก็บอีเมล รหัสผ่าน และรหัสกู้คืนไว้ในไฟล์ `test-account.local` (git ไม่เก็บไฟล์นี้) ห้ามใส่รหัสใน README เพราะ repo นี้เปิดสาธารณะ

PIN ตั้งเองตอนเข้าครั้งแรก ถ้าใช้ฐานข้อมูลอื่น บัญชีจะไม่อยู่ ให้กดสมัครในแอปด้วยอีเมลและรหัสผ่านเดิม ในตัวจำลอง iPhone ถ้าคีย์บอร์ดเป็นภาษาไทย ช่องรหัสผ่านจะพิมพ์เป็นอักษรไทย ให้สลับเป็นอังกฤษก่อน (กดรูปลูกโลกบนคีย์บอร์ด)

## แอปมือถือ

แอป iOS และ Android ห่อ build เดียวกับเว็บด้วย Capacitor

```bash
npm run mobile:ios      # build + sync แล้วเปิด Xcode
npm run mobile:android  # build + sync แล้วเปิด Android Studio
```

ไอคอนสร้างจาก `assets/icon.svg` ด้วย `npx @capacitor/assets generate --ios --android`
